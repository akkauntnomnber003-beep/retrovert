================================================================================
                          RATROVERT — MODDING GUIDE
                              (RatScript reference)
================================================================================

Этот документ — полное руководство по созданию модов для RatRovert.
Здесь есть всё: формат архива .retrovert, mod.json, синтаксис RatScript,
весь API (state, чат, файлы, сеть, AI, события, спавн врагов и т.д.),
готовые рецепты, частые ошибки и финальный пример мега-мода.

Все функции, упомянутые в этом файле, реально доступны в текущей сборке.
Найти исходник интерпретатора: scripts/mods/ratscript/Interpreter.gd
ModAPI: scripts/autoloads/ModAPI.gd
Шаблоны: res://mods/templates/  и  res://mods/templates_src/

--------------------------------------------------------------------------------
0. БЫСТРЫЙ СТАРТ ЗА 30 СЕКУНД
--------------------------------------------------------------------------------

  1. Создайте папку с любым именем, например `my_mod/`.
  2. Внутрь положите два файла:
       my_mod/mod.json
       my_mod/scripts/main.rrs
  3. Заархивируйте папку в ZIP, дайте расширение `.retrovert`:
       zip -r my_mod.retrovert my_mod
  4. Откройте в игре «Моды» → «Импорт» → выберите файл.
  5. Включите мод тумблером, перезапустите Run. Готово.

Минимальный mod.json:

  {
    "id": "my_mod",
    "name": "Мой мод",
    "version": "0.1.0",
    "author": "Я",
    "entry": "scripts/main.rrs"
  }

Минимальный main.rrs:

  on_load = func()
      chat_log("Привет из мода!")
  end


--------------------------------------------------------------------------------
1. ФОРМАТ ФАЙЛА МОДА (.retrovert)
--------------------------------------------------------------------------------

`.retrovert` — это обычный ZIP-архив с расширением `.retrovert`.
Игра распознает его в окне «Моды → Импорт» и распакует в:

  user://mods/<uuid>/

Где <uuid> — стабильный идентификатор, сгенерированный из поля `id` манифеста.
Папка пользователя зависит от ОС, но движок Godot всегда нормализует путь:

  Linux:   ~/.local/share/godot/app_userdata/RatRovert/mods/<uuid>/
  Windows: %APPDATA%/Godot/app_userdata/RatRovert/mods/<uuid>/
  Mac:     ~/Library/Application Support/Godot/app_userdata/RatRovert/mods/<uuid>/

Структура внутри архива:

  my_mod/
    mod.json              ← обязательно
    icon.png              ← опционально (показывается в списке модов)
    scripts/
      main.rrs            ← точка входа (имя/путь задаётся полем "entry")
      utils.rrs           ← можно подгружать через include(...)
    assets/               ← любые ваши файлы (тексты, JSON, спрайты)
    README.md             ← опциональное описание для пользователя

После установки игра показывает мод в «Моды», подгружает icon.png и
выводит описание из mod.json. Включить/выключить мод можно тумблером.


--------------------------------------------------------------------------------
2. mod.json — МАНИФЕСТ
--------------------------------------------------------------------------------

Все поля кроме `id`, `name`, `version` и `entry` — опциональны.

  {
    "id": "darkrift",                  // уникальный, латиница/цифры/_-
    "name": "Dark Rift",               // отображаемое имя
    "version": "1.2.0",                // semver
    "author": "Имя автора",
    "description": "Короткое описание мода для списка.",
    "entry": "scripts/main.rrs",       // путь относительно архива
    "icon": "icon.png",                // 64×64 или 128×128 PNG
    "tags": ["weapon", "ai", "chat"],  // фильтрация в каталоге
    "min_game_version": "1.0.0",       // если ниже — мод не загрузится
    "permissions": {
      "network": true,                 // даёт доступ к http_get/http_post/ai_chat
      "files": true                    // даёт доступ к file_read/file_write
    }
  }

Если `permissions` отсутствует — мод получает доступ к чату и базовым
функциям, но без сети и без записи файлов.


--------------------------------------------------------------------------------
3. RATSCRIPT — СИНТАКСИС
--------------------------------------------------------------------------------

RatScript — встроенный язык, синтаксис вдохновлён Lua + Godot. Скрипт
интерпретируется (tree-walking interpreter), не компилируется.

Комментарии:
  -- однострочный
  -- (многострочных нет; перенесите строку или комментируйте каждую)

Переменные:
  let x = 10              -- константа (тип выводится)
  var y = vec(0, 0)       -- изменяемая

Числа:        12, 3.14, -0.5
Строки:       "hello", 'hello'   (можно одинарные и двойные)
Булевы:       true, false
nil:          nil
Векторы:      vec(x, y)          -- встроенная функция, возвращает Vector2
Массивы:      [1, 2, 3]
Словари:      { id = "x", name = "Y", power = 5 }   -- ключи без кавычек

Условия:
  if hp < 1 then
      heal(1)
  elseif hp < 3 then
      log("low hp")
  else
      log("ok")
  end

Циклы:
  while x > 0 do
      x = x - 1
  end

  for i in range(0, 10) do
      log(i)              -- 0..9
  end

  for e in enemies() do
      damage_in_radius(e.position, 32, 1)
  end

Функции:
  func add(a, b)
      return a + b
  end

  -- лямбды:
  let mul = func(a, b) return a * b end

Операторы:
  + - * / %               -- арифметика
  ==  !=  <  >  <=  >=    -- сравнения
  and  or  not            -- логика
  ..                      -- конкатенация строк

Доступ к полям и индексам:
  player().position       -- Vector2
  enemy.type              -- String
  data[0]                 -- массив
  cfg["x"]                -- словарь

Управление потоком:
  break        -- выйти из ближайшего цикла
  continue     -- к следующей итерации
  return v     -- возврат из функции


--------------------------------------------------------------------------------
4. ТОЧКИ ВХОДА
--------------------------------------------------------------------------------

Интерпретатор смотрит на эти глобальные переменные в вашем скрипте:

  on_load   -- вызывается один раз при включении мода (после загрузки игры)
  on_tick   -- вызывается каждый кадр, аргумент: delta (float, в секундах)
  on_unload -- вызывается при отключении или выгрузке мода

Пример:

  on_load = func()
      chat_log("Мод запущен")
  end

  on_tick = func(delta)
      -- что-то делаем каждый кадр (осторожно — это горячий путь)
  end

  on_unload = func()
      chat_log("Мод выгружается")
  end

Подписки на события EventBus делайте через `on("название_сигнала") fn`:

  on("enemy_died", func(pos, enemy_type)
      state.add_coins(1)
      chat_log("Враг " .. enemy_type .. " пал.")
  end)

`on(...)` корректно прокидывает аргументы сигнала в вашу функцию.


--------------------------------------------------------------------------------
5. ПОЛНЫЙ СПИСОК ВСТРОЕННЫХ ФУНКЦИЙ
--------------------------------------------------------------------------------

Все эти функции доступны в глобальной области:

5.1  Лог и базовые типы
─────────────────────────
  log(...)                печатает в системный лог (видно в консоли Godot)
  print(...)              синоним log
  vec(x, y)               создаёт Vector2
  range(a, b) / range(n)  массив целых чисел [a..b) или [0..n)
  len(value)              длина строки/массива/словаря
  str(value)              приведение к строке
  lower(s) / upper(s)     регистр
  contains(s, substr)     true, если substr внутри s
  replace(s, from, to)    замена подстроки

5.2  Математика
─────────────────
  clamp(v, lo, hi)            ограничение
  rand()                      0..1
  randi(a, b)                 целое из [a..b]
  sin(x) cos(x) tan(x)        тригонометрия (в радианах)
  sqrt(x) abs(x)              корень / модуль
  floor(x) ceil(x) round(x)   округления
  min(a, b)  max(a, b)        минимум / максимум
  dist(a, b)                  расстояние между двумя Vector2

5.3  Состояние игрока (state)
───────────────────────────────
  state — это объект (словарь функций), не вызов!

  state.get("coins")              значение поля GameState
  state.set("coins", 99)          напрямую — осторожно
  state.add("hp", 1)              прибавить к полю
  state.add_coins(n)              удобный шорткат
  state.add_bombs(n)
  state.add_keys(n)
  state.heal(n)                   красные сердечки
  state.heal_soul(n)              соул-сердечки
  state.damage(n)                 нанести урон игроку

  Полезные поля GameState (для get/set):
    hp_red, hp_soul, hp_max
    coins, bombs, keys
    player_speed, player_damage, tear_rate, tear_speed, tear_range
    luck, auto_aim
    run_floor, run_seed
    кills_this_run, coins_collected_total

5.4  Предметы
───────────────
  item(d)                регистрирует пассивный/активный предмет:
                         d = { id, name, description, stats = {...},
                               active = false, sprite = "res://...png" }
  grant(item_id)         выдаёт предмет игроку прямо сейчас

  Поддерживаемые stats:
    player_damage, tear_rate, tear_speed, tear_range, luck,
    player_speed, hp_max, hp_red

5.5  Враги и спавн
────────────────────
  spawn(scene_path, pos)             спавнит сцену в текущей комнате
  enemies()                          массив текущих живых врагов
  player()                           ссылка на игрока (Node2D)
  damage_in_radius(pos, r, dmg)      урон всем врагам в радиусе

  Стандартные сцены врагов:
    "res://scenes/enemies/Fly.tscn"
    "res://scenes/enemies/Gaper.tscn"
    "res://scenes/enemies/Pooter.tscn"
    "res://scenes/enemies/Spider.tscn"
    "res://scenes/enemies/Leaper.tscn"
    "res://scenes/enemies/bosses/Larry.tscn"
    "res://scenes/enemies/bosses/Monstro.tscn"

5.6  Чат
──────────
  chat_send(sender, text, kind, sender_id)
       kind ∈ "info" "log" "system" "mod" "error" "enemy" "item"
       sender_id используется чтобы цветом отличать одного и того же
       NPC/моба от другого.
  chat_log(text)         от имени мода, kind=mod
  chat_error(text)       от имени мода, kind=error
  chat_enemy(name, text, id)
  chat_item(name, text, id)
  chat_clear()
  chat_show() / chat_hide()

Чат — это горизонтальное окно в верхней части экрана, 5 строк, с авто-
прокруткой и буфером на 200 сообщений. Игрок ввод не делает; всё пишут
моды и сама игра. Цвет/префикс зависит от kind.

5.7  Файлы (песочница)
────────────────────────
  file_read(path, default)         читать как строку
  file_write(path, content)        записать
  file_list(rel_dir)               список файлов
  file_exists(path)                bool
  file_remove(path)                удалить

  Все пути относительные. Корнем считается:
     user://mods/<uuid>/data/
  Любые `..` или абсолютные пути отбрасываются.

5.8  Сеть (нужно permissions.network = true)
───────────────────────────────────────────────
  http_get(url, headers=[])              → request_id (int)
  http_post(url, body_string, headers=[])→ request_id
  http_cancel(rid)                       → null

  Ответ приходит сигналом `net_response`:
      on("net_response", func(rid, code, body) ... end)

5.9  AI / LLM (нужен ключ OpenRouter в Настройках)
─────────────────────────────────────────────────────
  ai_chat(prompt)                          → request_id
  ai_chat(prompt, model)                   указать модель
  ai_chat_as(prompt, sender, sender_id)    как обычный chat_send, но текст
                                            возьмётся из AI ответа
  ai_chat_as(prompt, sender, sender_id, model)

  Ответ так же приходит сигналом `net_response`, но в body уже извлечён
  текст ответа модели (а не сырой JSON). Если модель/ключ не заданы —
  фоллбэк на "google/gemma-3-12b-it:free".

  Ключ задаётся в игре: Главное меню → Настройки → API ключи →
  «OpenRouter ключ». Сохраняется в user://settings/api_keys.cfg.
  В репозиторий ключи никогда не попадают.

  Если ключ не задан, ai_chat вернёт -1, и в лог запишется ошибка.

5.10 Камера, звук, утилиты
────────────────────────────
  shake(strength=4, duration=0.3)     тряска экрана
  sfx("name")                         воспроизвести звук из библиотеки
  now()                               время в секундах (float)
  keys(dict)                          ключи словаря

5.11 Работа с JSON
────────────────────
  json_parse(text)                    String → Dictionary/Array/...
  json_stringify(value)               value → String

  api_key("openrouter")               прочитать ключ (если есть)
  api_has_key("openrouter")           true, если ключ установлен

6. ВСЕ СИГНАЛЫ EventBus
--------------------------------------------------------------------------------

Можно подписываться через on("имя", func(...) end):

  ИГРОК

  МОДЫ / ЧАТ / СЕТЬ

7. ГОТОВЫЕ РЕЦЕПТЫ
--------------------------------------------------------------------------------

Рецепт 1. Каждые 5 секунд спавним муху рядом с игроком:
  var t = 0.0
  on_tick = func(delta)
      t = t + delta
      if t >= 5.0 then
          t = 0.0
          spawn("res://scenes/enemies/Fly.tscn",
                player().position + vec(64, 0))
      end
  end

Рецепт 2. Бесконечные монеты на каждого убитого врага:
  on("enemy_died", func(pos, type)
      state.add_coins(2)
  end)

Рецепт 3. Враг шепчет в чат при появлении:
  on("enemy_spawned", func(enemy)
      chat_enemy("Pooter", "Ты слишком близко...", str(enemy))
  end)

Рецепт 4. AI-комментатор после смерти босса:
  on("boss_died", func(_pos)
      ai_chat_as("Опиши падение босса одной злорадной фразой.",
                 "Тёмный голос", "darkrift_npc")
  end)

Рецепт 5. Сохраняем счётчик убийств в файл мода:
  on("enemy_died", func(_p, _t)
      var n = json_parse(file_read("kills.json", "0"))
      file_write("kills.json", str(n + 1))
  end)

Рецепт 6. Регистрация нового пассивного предмета:
  on_load = func()
      item({
          id = "tiny_tear",
          name = "Tiny Tear",
          description = "+1 урон, +25% скорость стрельбы",
          stats = { player_damage = 1.0, tear_rate = 0.25 }
      })
      grant("tiny_tear")
  end

Рецепт 7. Удалённая конфигурация через HTTP:
  on_load = func()
      http_get("https://example.com/balance.json", [])
  end
  on("net_response", func(rid, code, body)
      if code == 200 then
          let cfg = json_parse(body)
          state.set("tear_rate", cfg["tear_rate"])
      end
  end)


--------------------------------------------------------------------------------
8. БЕЗОПАСНОСТЬ И ПЕСОЧНИЦА
--------------------------------------------------------------------------------

* Скрипты НЕ имеют доступа к произвольным файлам ОС.
* `file_*` работает только внутри `user://mods/<uuid>/data/`.
* HTTP-запросы и AI идут только если в `mod.json.permissions.network`
  стоит `true`, иначе вызовы будут отклонены.
* Ключи API хранятся в `user://settings/api_keys.cfg` и не попадают
  в репозиторий. Мод видит только функцию `api_has_key(...)` и сам
  значение ключа НЕ читает (этим занимается NetAPI/AI слой).
* Если хотите получить ключ в скрипте напрямую — используйте `api_key(...)`,
  но крайне не рекомендуется логировать или отправлять его в чат.


--------------------------------------------------------------------------------
9. ОШИБКИ И ОТЛАДКА
--------------------------------------------------------------------------------

* Все ошибки парсинга и рантайма попадают в системный чат (`error`) и в
  лог Godot. Откройте «Чат», чтобы видеть их в игре.
* Если мод не появляется в списке — проверьте mod.json (валидный JSON?).
* Если иконка не отображается — поле `icon` должно указывать на PNG
  внутри архива (например `icon.png`).
* Используйте `chat_log(...)` как `print` — он надёжно покажет
  значения переменных прямо в игре.


--------------------------------------------------------------------------------
10. ШАБЛОНЫ
--------------------------------------------------------------------------------

В `res://mods/templates_src/` лежат готовые шаблоны:

  item_template        — регистрирует новый пассивный предмет
  enemy_template       — спавнит врага и заставляет его говорить в чат
  event_template       — подписывается на все важные сигналы
  chat_template        — чат-бот NPC на OpenRouter
  cheat_fragments      — авто-аим + +99 монет + быстрый темп стрельбы
  mega_template        — большой пример со всем сразу (см. ниже)

В «Моды → Шаблоны» можно одной кнопкой установить любой из них.


--------------------------------------------------------------------------------
11. МЕГА-ШАБЛОН — ПОЛНЫЙ ПРИМЕР
--------------------------------------------------------------------------------

См. файл `res://mods/templates_src/mega_template/scripts/main.rrs`.

Что делает мега-шаблон:
  * Регистрирует новый пассивный предмет «Crimson Lens»
       (+1 dmg, +25% скорость стрельбы, +0.5 luck).
  * При входе в boss-комнату — призывает 4 муху-помощника, дружелюбных.
    Они каждые 6 секунд кричат в чат от своих имён.
  * При смерти любого врага — кидает кровь и говорит фразу через
    OpenRouter (если ключ задан); иначе — заранее заготовленную.
  * Слушает `room_entered` и при заходе в магазин — пишет совет.
  * Слушает `boss_died` — кидает дополнительные монеты и сохраняет
    статистику в файл `mod data/kills.json`.
  * Раз в 12 секунд тёмный голос («Dark Rift») оставляет в чате
    мрачную AI-сгенерированную фразу.

Откройте файл целиком — он закомментирован построчно.
