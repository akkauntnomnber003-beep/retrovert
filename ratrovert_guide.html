01

Быстрый старт за 30 секунд

Минимальный мод от нуля до работающего — четыре шага.

1
Создайте папку мода
Имя папки — любое. Внутрь кладём mod.json и scripts/main.rrs.
2
Напишите минимальный mod.json
mod.json 
{
  "id":      "my_mod",
  "name":    "Мой первый мод",
  "version": "0.1.0",
  "author":  "Я",
  "entry":   "scripts/main.rrs"
}
3
Напишите scripts/main.rrs
RatScript 
on_load = func()
    chat_log("Привет из мода!")
end

on_tick = func(delta)
    -- вызывается каждый кадр
end
4
Запакуйте в .retrovert и импортируйте
bash 
# ВАЖНО: запускать из папки мода, не снаружи!
cd my_mod
zip -r ../my_mod.retrovert mod.json scripts/ README.md

Откройте в игре Моды → Импорт, выберите файл, включите тумблером и перезапустите Run.

⚠ Частая ошибка: если упаковать как zip -r mod.zip папка/, то mod.json окажется внутри подпапки и мод не импортируется. Всегда пакуйте из папки мода.
02

Формат файла .retrovert

.retrovert — это обычный ZIP-архив с другим расширением.

Структура архива 
my_mod.retrovert  ← ZIP-архив
├── mod.json          ← обязательно (в корне!)
├── icon.png          ← 64×64 или 128×128 PNG (опционально)
├── README.md         ← описание для пользователей
├── scripts/
│   ├── main.rrs      ← точка входа (путь в "entry")
│   └── utils.rrs     ← вспомогательные файлы
├── assets/           ← любые ресурсы мода
└── data/             ← папка для файловой песочницы

Куда устанавливается мод

Пути установки 
Linux:   ~/.local/share/godot/app_userdata/RatRovert/mods/<uuid>/
Windows: %APPDATA%/Godot/app_userdata/RatRovert/mods/<uuid>/
Mac:     ~/Library/Application Support/Godot/app_userdata/RatRovert/mods/<uuid>/

<uuid> генерируется из поля id в mod.json и остаётся стабильным.

03

mod.json — манифест

Обязательные поля: id, name, version, entry. Остальное опционально.

mod.json — полный пример 
{
  "id":               "darkrift",          // уникальный, латиница/цифры/_-
  "name":             "Dark Rift",
  "version":          "1.2.0",             // semver
  "author":           "Имя автора",
  "description":      "Короткое описание.",
  "entry":            "scripts/main.rrs",
  "icon":             "icon.png",           // 64×64 или 128×128 PNG
  "tags":             ["weapon", "ai", "chat"],
  "min_game_version": "1.0.0",
  "permissions": {
    "network": true,   // http_get/http_post/ai_chat
    "files":   true    // file_read/file_write
  }
}
ПолеТипОбяз.Описание
idstringreqУникальный идентификатор. Только латиница, цифры, _ и -
namestringreqОтображаемое имя в списке модов
versionstringreqВерсия в формате semver: 1.0.0
entrystringreqПуть к главному скрипту относительно корня архива
authorstringoptИмя автора
descriptionstringoptОписание в каталоге модов
iconstringoptПуть к PNG-иконке внутри архива
tagsarrayoptТеги для фильтрации в каталоге
min_game_versionstringoptМинимальная версия игры. Если ниже — мод не загрузится
permissions.networkbooloptРазрешает http_get, http_post, ai_chat
permissions.filesbooloptРазрешает file_read, file_write и т.д.

var y = 3.14         -- изменяемая
var name = "Rat"
var flag = true
var empty = nil

if hp < 1 then
    heal(1)
elseif hp < 3 then
    log("low hp")
else
    log("ok")
end
Циклы
while x > 0 do
    x = x - 1
end

for i in range(0, 10) do
    log(i)   -- 0..9
end

for e in enemies() do
    log(e.type)
end

    return a + b
end

    return a * b
end
Коллекции

log(arr[0])        -- 1

-- словарь
var d = { id = "x", val = 5 }
log(d["id"])      -- "x"
log(d.val)        -- 5
Операторы
-- арифметика

-- сравнения
==  !=  <  >  <=  >=

-- логика

06

Точки входа и события

Три глобальных переменные-функции и подписки через on().

▶
on_load
Вызывается один раз при включении мода. Сюда — регистрация предметов, загрузка данных, первые сообщения.
⟳
on_tick
Вызывается каждый кадр. Аргумент delta — время в секундах между кадрами. Это горячий путь — не делайте тут дорогих операций.
■
on_unload
Вызывается при отключении или выгрузке мода. Сохраняйте тут данные через file_write().
📡
on("сигнал", func)
Подписка на сигнал EventBus. Аргументы функции соответствуют аргументам сигнала. Работает в любом месте скрипта.
RatScript — все точки входа 
-- Инициализация
on_load = func()
    chat_log("Мод запущен")
end

-- Каждый кадр (delta = секунды с прошлого кадра)
on_tick = func(delta)
    -- таймер
end

-- При выключении
on_unload = func()
    file_write("data.json", json_stringify(my_data))
end

-- Подписка на событие
on("enemy_died", func(pos, enemy_type)
    chat_log("Убит: " .. enemy_type)
end)

-- Альтернативный синтаксис подписки
on("player_spawned") func(player)
    chat_log("Игрок появился!")
end
⚡ on_tick и производительность: избегайте в on_tick дорогих операций (file_write, ai_chat, spawn). Используйте таймеры: накапливайте t = t + delta и выполняйте действие только когда t >= 5.0, затем сбрасывайте t = 0.

Регистрация предмета 
item({

-- Спавн рядом с игроком со случайным смещением
func spawn_near(scene, spread)
    let p = player()
    if p == nil then return end
    spawn(scene, p.position + vec(randi(-spread, spread), randi(-spread, spread)))
end

-- Спавн по углам комнаты (стандартная комната ~1040×608)
func spawn_corners(scene)
    let p = player()
    if p == nil then return end
    var offs = [
        vec(-420, -220), vec(420, -220),
        vec(-420,  220), vec(420,  220)
    ]
    for o in offs do
        spawn(scene, p.position + o)
    end
end

-- Взрыв: урон в радиусе 120px
let center = player().position
damage_in_radius(center, 120, 3)

API: Чат

Чат — горизонтальное окно в верхней части. 5 видимых строк, буфер 200 сообщений. Цвет зависит от kind.

ФункцияОписание
chat_send(sender, text, kind, id)Полный вызов. kind: info log system mod error enemy item
chat_log(text)От имени мода, kind=mod
chat_error(text)От имени мода, kind=error (красный)
chat_enemy(name, text, id)Сообщение от врага/NPC
chat_item(name, text, id)Сообщение от предмета
chat_clear()Очистить чат
chat_show()Показать чат
chat_hide()Скрыть чат
Примеры 
-- Простое сообщение от мода
chat_log("Мод запущен!")

-- Ошибка (красный цвет)
chat_error("Что-то пошло не так")

-- NPC-враг говорит
chat_enemy("Тёмная Муха", "Я с тобой, носитель.", "darkfly_1")

-- Предмет говорит
chat_item("Кровавая Слеза", "Активирован!", "blood_tear")

-- Полный формат с кастомным kind
chat_send("Голос", "Добро пожаловать в бездну.", "info", "abyss_voice")

API: Файлы (песочница)

Нужно permissions.files = true в mod.json. Корень: user://mods/<uuid>/data/

ФункцияВозвратОписание
file_read(path, default)stringЧитает файл. Если нет — возвращает default
file_write(path, content)—Записывает строку в файл
file_exists(path)boolПроверяет существование файла
file_list(rel_dir)ArrayСписок файлов в папке
file_remove(path)—Удаляет файл
Сохранение и загрузка данных 
-- Сохранить счётчик
file_write("kills.json", str(kills_total))

-- Загрузить обратно
let raw = file_read("kills.json", "0")
var kills = json_parse(raw)
if kills == nil then kills = 0 end

-- Сохранить сложный объект
let data = { kills = 42, bosses = 3, runs = 7 }
file_write("stats.json", json_stringify(data))

-- Загрузить и использовать
if file_exists("stats.json") then
    let s = json_parse(file_read("stats.json", "null"))
    chat_log("Убийств: " .. str(s["kills"]))
end
🔒Пути типа ../ или абсолютные автоматически отбрасываются. Файлы доступны только внутри папки мода.

API: Сеть / HTTP

Нужно permissions.network = true. Запросы асинхронные — ответ приходит сигналом net_response.

ФункцияВозвратОписание
http_get(url, headers)int (rid)GET-запрос. headers — массив строк
http_post(url, body, headers)int (rid)POST-запрос. body — строка
http_cancel(rid)—Отменить запрос по rid
Удалённая конфигурация 
var config_rid = -1

on_load = func()
    config_rid = http_get("https://example.com/balance.json", [])
end

on("net_response", func(rid, code, body)
    if rid != config_rid then return end  -- не наш запрос
    if code == 200 then
        let cfg = json_parse(body)
        state.set("tear_rate", cfg["tear_rate"])
        chat_log("Конфигурация загружена!")
    else
        chat_error("Ошибка HTTP: " .. str(code))
    end
end)

API: AI / LLM

Нужны permissions.network = true и ключ OpenRouter в настройках игры. Фоллбэк: google/gemma-3-12b-it:free.

ФункцияОписание
ai_chat(prompt)Запрос к AI. Ответ — через net_response, body уже содержит текст (не JSON)
ai_chat(prompt, model)С указанием конкретной модели OpenRouter
ai_chat_as(prompt, sender, id)AI-ответ сразу отправляется в чат от имени sender
ai_chat_as(prompt, sender, id, model)С указанием модели
api_has_key("openrouter")Проверяет наличие ключа. Всегда проверяйте перед вызовом!
api_key("openrouter")Читает ключ. Не логируйте его в чат!
AI-NPC с фоллбэком 
var fallback = [
    "Тень падает быстрее, чем эхо.",
    "Они пришли из тьмы. Ты отправил их обратно.",
]

func pick(arr)
    return arr[randi(0, len(arr) - 1)]
end

on("boss_died", func(_pos)
    if api_has_key("openrouter") then
        ai_chat_as(
            "Скажи одну злорадную фразу (≤80 знаков) о падении босса, на русском.",
            "Тёмный Голос", "dark_voice"
        )
    else
        chat_enemy("Тёмный Голос", pick(fallback), "dark_voice")
    end
end)
🔑 Где задать ключ: Главное меню → Настройки → API ключи → «OpenRouter ключ». Ключ хранится в user://settings/api_keys.cfg и никуда не отправляется кроме OpenRouter.

Таймер и периодический спавн врагов
▶

Каждые 5 секунд спавним муху рядом с игроком. Паттерн «накопитель delta».

RatScript
var t = 0.0

on_tick = func(delta)
    t = t + delta
    if t >= 5.0 then
        t = 0.0
        let p = player()
        if p != nil then
            spawn("res://scenes/enemies/Fly.tscn",
                  p.position + vec(64, 0))
        end
    end
end

Постоянное сохранение статистики
▶

Счётчик убийств сохраняется между сессиями в файле мода.

RatScript
var kills = 0

on_load = func()
    let raw = file_read("kills.json", "0")
    let v = json_parse(raw)
    if v != nil then kills = v end
    chat_log("Всего убийств: " .. str(kills))
end

on("enemy_died", func(_p, _t)
    kills = kills + 1
    file_write("kills.json", str(kills))
end)

on_unload = func()
    file_write("kills.json", str(kills))
end

Система волн в комнате
▶

Каждые 8 секунд, если врагов меньше 5, появляется новая волна.

RatScript
var t = 0.0
var wave_on = false

on("room_entered", func(pos, type)
    wave_on = (type == 0)  -- только обычные комнаты
    t = 5.0               -- первая волна через 5 сек
end)

on("room_cleared", func(_p)
    wave_on = false
end)

on_tick = func(delta)
    if not wave_on then return end
    t = t + delta
    if t >= 8.0 then
        t = 0.0
        if len(enemies()) < 5 then
            let p = player()
            if p != nil then
                spawn("res://scenes/enemies/Fly.tscn",
                      p.position + vec(randi(-200,200), randi(-200,200)))
            end
        end
    end
end

Удалённая конфигурация (HTTP)
▶

Загрузка баланса мода с внешнего сервера при старте.

RatScript
var my_rid = -1

on_load = func()
    my_rid = http_get("https://myserver.com/mod_config.json", [])
end

on("net_response", func(rid, code, body)
    if rid != my_rid then return end
    if code != 200 then
        chat_error("Сервер недоступен: " .. str(code))
        return
    end
    let cfg = json_parse(body)
    state.set("player_damage", cfg["base_damage"])
    chat_log("Конфигурация загружена с сервера!")
end)

Полный пример мода

Каркас мода, использующего все основные возможности API. Подходит как основа для любого мода.

scripts/main.rrs — полный каркас 
-- ── Состояние ────────────────────────────────────────────
var t_wave    = 0.0
var t_voice   = 0.0
var kills     = 0
var streak    = 0
var wave_on   = false
var cur_floor = 1

var voice_lines = [
    "Тень падает быстрее, чем эхо.",
    "Они пришли из тьмы. Ты отправил их обратно.",
    "Бездна считает. Она всегда считает."
]

-- ── Утилиты ──────────────────────────────────────────────
func pick(arr)
    return arr[randi(0, len(arr) - 1)]
end

func voice(prompt)
    if api_has_key("openrouter") then
        ai_chat_as(prompt, "Голос", "npc_voice")
    else
        chat_enemy("Голос", pick(voice_lines), "npc_voice")
    end
end

func enemy_for_floor()
    if cur_floor <= 1 then return "res://scenes/enemies/Fly.tscn" end
    if cur_floor == 2 then return "res://scenes/enemies/Gaper.tscn" end
    if cur_floor == 3 then return "res://scenes/enemies/Pooter.tscn" end
    if cur_floor == 4 then return "res://scenes/enemies/Spider.tscn" end
    return "res://scenes/enemies/Leaper.tscn"
end

func save()
    file_write("stats.json", json_stringify({ kills = kills }))
end

-- ── Загрузка ──────────────────────────────────────────────
on_load = func()
    chat_log("Мод запущен!")

    item({
        id = "void_lens", name = "Линза Пустоты",
        description = "+1 урон, +0.5 удача",
        stats = { player_damage = 1.0, luck = 0.5 }
    })
    grant("void_lens")

    if file_exists("stats.json") then
        let s = json_parse(file_read("stats.json", "null"))
        if s != nil then kills = s["kills"] end
    end
    chat_log("Убийств всего: " .. str(kills))
end

-- ── Тик ──────────────────────────────────────────────────
on_tick = func(delta)
    t_wave  = t_wave  + delta
    t_voice = t_voice + delta

    if wave_on and t_wave >= 8.0 then
        t_wave = 0.0
        if len(enemies()) < 5 then
            let p = player()
            if p != nil then
                spawn(enemy_for_floor(),
                      p.position + vec(randi(-180,180), randi(-180,180)))
            end
        end
    end

    if t_voice >= 15.0 then
        t_voice = 0.0
        voice("Скажи мрачную фразу (≤80 знаков), на русском.")
    end
end

-- ── События ───────────────────────────────────────────────
on("floor_entered", func(n)
    cur_floor = n
    state.add_coins(n * 2)
end)

on("room_entered", func(_pos, rtype)
    wave_on = (rtype == 0)
    t_wave = 5.0
end)

on("room_cleared", func(_p)   wave_on = false end)

on("enemy_died", func(_p, _t)
    kills  = kills  + 1
    streak = streak + 1
    if randi(0, 3) == 0 then state.add_coins(1) end
    if streak % 5 == 0 then
        chat_log("СЕРИЯ x" .. str(streak) .. "!")
    end
    save()
end)

on("player_damaged", func(_a)  streak = 0  end)

on("boss_died", func(_p)
    state.add_coins(10 + cur_floor * 2)
    state.add_keys(1)
    shake(6.0, 0.5)
    voice("Злорадная фраза о падении босса, ≤80 знаков.")
end)

on("player_died", func()
    chat_error("КОНЕЦ. Убийств: " .. str(kills))
    save()
end)

on("net_response", func(rid, code, body)
    if code != 200 then
        chat_error("HTTP " .. str(code))
    end
end)

on_unload = func()
    save()
    chat_log("Мод выгружен. Убийств: " .. str(kills))
end

Безопасность и песочница

🔒
Файловая изоляция
file_* работает только внутри user://mods/<uuid>/data/. Пути ../ и абсолютные пути автоматически отбрасываются.
🌐
Сетевые разрешения
HTTP-запросы и AI доступны только если в mod.json указано "permissions": {"network": true}.
🔑
Ключи API
Ключ OpenRouter хранится в user://settings/api_keys.cfg и никогда не попадает в репозиторий. Не логируйте результат api_key()!
🚫
Нет системного доступа
Скрипты не имеют доступа к произвольным файлам ОС, процессам или сети за пределами заявленного.

FAQ

?
Можно ли управлять камерой (позиция, зум)?
▶

Нет. RatScript предоставляет только shake(strength, duration). Позиционирование и зум камеры — внутренний уровень движка Godot. Единственный способ влиять на камеру — тряска.

?
Можно ли задать врагу кастомный AI/патфайндинг?
▶

Нет. spawn() создаёт готовые сцены врагов, которые содержат встроенный AI с NavMesh-навигацией. Мод управляет только позицией спавна и типом врага. После появления враг сам найдёт игрока. Кастомный per-frame AI из RatScript написать невозможно.

?
Как включить несколько модов одновременно?
▶

Все активные моды работают одновременно. Каждый мод получает свои подписки на EventBus. Конфликты возможны если два мода устанавливают одинаковый item.id — убедитесь что id уникальны.

?
Поддерживаются ли многострочные комментарии?
▶

Нет. Только однострочные комментарии через --. Для блока комментариев комментируйте каждую строку.

?
Как разделить код на несколько файлов?
▶

Документация упоминает функцию include(...) для подгрузки дополнительных .rrs файлов. Пример: include("scripts/utils.rrs"). Основной файл указывается в поле entry манифеста.

?
Какие модели AI доступны через ai_chat?
▶

Любые модели из OpenRouter. Фоллбэк без указания модели — google/gemma-3-12b-it:free. Пример: ai_chat(prompt, "anthropic/claude-3-haiku"). Полный список: openrouter.ai/models.
