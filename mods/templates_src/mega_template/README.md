# Mega Template — Dark Rift Suite

Эталонный мод, который показывает все основные возможности RatScript:

* Регистрирует пассивный предмет **Crimson Lens** (+1 dmg, +25% темп
  стрельбы, +0.5 luck) и сразу выдаёт его игроку.
* Каждые 6 секунд призывает дружелюбную **тёмную муху-помощника**
  (макс 4). Каждая шепчет в чат при появлении.
* Раз в 12 секунд **Dark Rift** говорит в чат мрачную AI-фразу
  (через OpenRouter), если в Настройках задан ключ. Иначе берёт
  фразу из заранее заготовленного массива.
* Слушает `enemy_died` — считает убитых, иногда роняет монетку,
  сохраняет счётчик в `data/kills.json`.
* Слушает `boss_died` — даёт +15 монет, +2 бомбы, +1 ключ, AI-фраза.
* Слушает `room_entered` — даёт подсказки в магазине / секрете.
* Слушает `player_damaged` — мухи реагируют сообщением в чат.
* В `on_unload` корректно сохраняет статистику.

## Использование AI

Откройте «Главное меню → Настройки → API ключи → OpenRouter ключ».
Введите свой ключ с https://openrouter.ai/keys и сохраните.
Ключ хранится локально в `user://settings/api_keys.cfg` и в репозиторий
никогда не попадает.

Если ключ не задан — мод всё равно работает, но без AI-фраз.

## Файлы

* `mod.json` — манифест, помечен `permissions.network = true` и
  `permissions.files = true`.
* `scripts/main.rrs` — основной скрипт, ~80 строк, подробно
  закомментирован.
* `data/kills.json` — создаётся автоматически после первого убийства.
