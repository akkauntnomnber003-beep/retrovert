# Coin Doubler

Удваивает каждую подобранную монету и даёт +50 монет в начале забега.

## Установка

1. Открыть в игре главное меню → Mods.
2. Импортировать архив `coin_doubler.retrovert`.
3. Включить мод.

## Сборка

```bash
cd mods/examples/coin_doubler
zip -r ../coin_doubler.retrovert mod.json scripts/ README.md
```
