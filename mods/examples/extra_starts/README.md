# Extra Starts

Регистрирует пассивный предмет "Rat Booster" (+30% урон, +20% скорость) и выдаёт его в начале забега.

## Сборка `.retrovert`

```bash
cd mods/examples/extra_starts
zip -r ../extra_starts.retrovert mod.json scripts/ README.md
```

Импортируйте полученный архив через **Mods → Import**.
